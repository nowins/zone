# Zone 质量验证

先读项目 [AGENTS.md](../../../AGENTS.md) 及改动涉及的专题。此技能复用项目规则和脚本，不替代其中的必要验证，也不增加推送、发布、设备或用户数据操作权限；当前会话已有授权继续有效。

## 选测与执行

从项目根运行 `npm run qa -- --layer plan --base origin/main`。审查基线若不同，使用实际 PR／任务基线。脚本同时读取已提交、暂存、未暂存和未跟踪文件路径；路径建议只作入口，AI 仍要读 diff，补充跨模块影响，不能为得到通过结论删掉必须验证的层。

- `--layer fast`：差异检查、生产前端构建、Node 回归；涉及原生时加锁定依赖的 Rust 检查与单测。纯文档只检查差异。
- `--layer artifact`：在独立构建目录生成真实 CI 身份 exe，检查签名匹配的驱动，再运行真实产物 smoke。
- `--layer faults`：同一真实产物流程加 SQLite 写锁／重试与不可用来源保留；只覆盖 `result.json` 明列的案例。
- `--layer auto`：执行本次路径建议的可运行层；仍缺的必要专用层使结果为 incomplete，而不是通过。

矩阵的 incomplete 表示建议层仍有缺口；是否阻塞当前交付，按用户范围和 AGENTS 的必要验证判断。已完成的真实人工流程另列证据，不把尚未建立的自动基线升级成所有界面修改的新前置条件；失败断言仍必须保留并处理。

结果在 `.tmp/qa/`，包含命令、退出码、日志、来源 SHA、工作区是否有未提交改动、产物 hash 和 passed／failed／not-run 矩阵。日志和测试退出码优先于 AI 的解释。先核对实际执行、正数测试数量和产物来源，再作结论；不要编辑确定性结果来改变状态。

## 证据与失败处理

读取失败命令日志，区分代码回归、测试缺陷、环境／依赖问题和缺少前提；原因不明就保留不确定性。保留失败截图、结构化结果、来源和 exe SHA256。截图存在不等于视觉比较通过，Range 通过也不等于扬声器有声音。

在授权范围内从最小可复现输入补回归案例，先确认案例能暴露问题，再修复并重跑受影响层。AI 可选测、设计夹具、审阅截图和提出实现，但不得用主观判断覆盖失败断言、放宽阈值、跳过失败测试或自动接受视觉／性能新基线。不要把重跑偶然变绿当作原因已消除。

真实产物入口和边界见 [发布文档](../../../packaging/README.md#github-ci-与原生产物测试)。脚本校验 exe hash、内嵌 `com.zone.player.ci.run-*` 身份并拒绝已有资料目录；只使用生成的 WAV、专用 profile 和这次 CI 身份的数据库。不要改真实资料库、宿主 ACL／磁盘、系统音频设备或结束用户应用；运行中的普通 exe 导致构建受阻时，用隔离目标目录。

## 专用环境与停止条件

- artifact／faults 需要可交互的 Windows x64、WebView2 和匹配驱动；缺少时记录具体前提，继续独立 fast 检查，不换成 mock 冒充原生产物测试。
- 目前故障层不覆盖磁盘满、真实文件权限／损坏库等全部场景；未实现或未执行的案例明确列出，不能概括为故障恢复全部通过。
- 视觉／性能层需要已批准参考和固定窗口、DPI、字体、夹具／参考机；缺少时只交付候选证据与差异，不自动建立或更新通过基线。
- 音频／设备层需要专用客户端、录回／设备和相应授权。CI 的 Windows Server 不代表 Windows 10/11 客户端或真实硬件。
- 安装生命周期使用项目已有 `npm run test:msix:hyperv -- -Inventory` 与[专用 VM 矩阵](../../../packaging/README.md#hyper-v-安装升级与卸载矩阵)；没有匹配包、身份、快照或测试账号时停止安装动作，不对日常宿主试装。

失败、来源/hash 不符或越过隔离边界时停止依赖动作。最终交付必须列明每层通过／失败／未执行、精确命令和证据、未覆盖场景及剩余前提；AI 的建议另列，不能充当测试通过证据。不需要 API key、付费模型服务或持久凭据。
